## 📥 Hướng Dẫn Cài Đặt (Chỉ 1 Click)

### Cách 1: Dùng Script Tự Động (Khuyên dùng)
1. Clone repo này về máy:
   ```bash
   git clone https://github.com/TaHoang715/Agent-skills.git
   cd Agent-skills
   ```
2. **Trên Windows**: Click đúp vào file **`install.bat`**.
3. **Trên macOS / Linux**: Chạy lệnh `chmod +x install.sh && ./install.sh`.

---

## 🔄 Hướng Dẫn Cập Nhật Kỹ Năng Mới Nhất

Mỗi khi muốn lấy các skill mới nhất mà GitHub Actions vừa đồng bộ:
* **Trên Windows**: Click đúp vào file **`update.bat`**.
* **Trên macOS / Linux**: Chạy lệnh `./update.sh`.
