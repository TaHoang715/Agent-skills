# Antigravity Global Agent Rules Template for SEP490 Capstone Project

Paste this configuration into your Antigravity IDE global rules or `.agents/AGENTS.md` file:

```markdown
# SEP490 Project Rules & Governance

1. **Core Laws**: Always follow Andrej Karpathy's 4 Core Laws (Think Before Coding, Simplicity First, Surgical Edits, Goal-Driven Execution).
2. **Backend (.NET 8+)**: Use ASP.NET Core Web API, EF Core, Repository Pattern, Async/Await, and Global Exception Handler.
3. **Frontend (Next.js)**: Use Next.js App Router, Server Components for initial load, Zustand for Client State, and TailwindCSS Dark Mode (Slate-950).
4. **Database**: Use PostgreSQL 16 & Npgsql EF Core provider. Never execute raw destructive SQL queries without user confirmation.
5. **Testing**: Run `dotnet test` and `npm test` to verify changes before marking tasks as resolved.
```
